# editbay

A native (omarchy first) marriage of features found in final cut pro, logic pro, premier pro, after effects, davinci studio, and the like.

## features

- Best in class clip management, editing, and compositing.
- Top of the line audio mixing and mastering.
- Unrivaled motion graphic production.
- Stunning vfx workflows and built in library of audi, video, title, and transition effects.
- Built in support for all major video formats.
- Built in support for all major audio formats.
- Built in support for all major image formats.
- Complete feature parity with top competitors PLUS built-in MCP for agents to drive the UI through code and agent computer use.
- Cloud collabs for approvals, comments, reviews, revisions and frame level annotations. (Think lawn)

## supports

- X86_64 and ARM64 Linux.
