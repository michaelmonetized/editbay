# Keyboard authoring

Create a project with Ctrl+N. In Timeline, Tab to **Create empty sequence** and
press Enter. Expand **Titles and fades**, enter title text and the retained font
path, then choose **Create title source**. **Create cut** places that source in
an editable sequence. These actions use the same document commands, undo and
recovery as media edits.

Tab moves through controls. Source, record, track and tool selectors accept
arrows and Home/End while focused. Enter or Space activates a focused action.
Each title, range, fade and slip field has a stable identity and visible name.

F8 focuses timeline content. Page Up/Down selects clips; Shift extends selection.
Up/Down and Home/End move through focused clip rows. Left/Right applies the chosen
clip tool by one frame; Shift uses ten frames, Alt slips and Ctrl rolls. E appends,
W inserts, S splits at the record frame and Delete removes the selected clip.
Text fields and other focused controls keep their own keys. Busy or disabled
timeline controls cannot submit an edit. Enter commits a property draft and
Escape cancels it.

Ctrl+F6 opens **Arrange panels**. Choose a panel and an action, then Tab to Apply.
Panels can be restored, focused, docked, floated, tabbed together or closed.
Floating dimensions apply once, so later manual resizing remains available.
F6 and Shift+F6 move between visible panel tabs. Workspace choices save with
EditBay preferences, separately from the document.

Import, open, save and export retain the existing native file chooser and worker
paths. No keyboard helper replaces media processing or delivery. This source
does not establish operating-system file chooser behavior, screen-reader
announcements, physical sound/display behavior, or the later caption/multicam
fields awaiting the common video integration.
